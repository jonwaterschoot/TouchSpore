# TouchSpore

Generative firmware for the Synthux Simple Touch (Daisy Seed, MPR121). See README.md for controls and build.

All prose (README, code comments, commit messages) follows @.claude/rules/writing-style.md.

Commit directly to `main`. Use a branch only when asked. Pushing to `main` starts a browser build, so run `make` first and push finished work.
